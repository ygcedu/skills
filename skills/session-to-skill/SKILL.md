# 会话转 Skill

从当前或近期会话中，提炼出可复用的 agent skill。

## 概述

本 skill 把一次成功的会话流程，转化为可移植、可复用的 agent skill。它会将会话中的隐性知识（提示词、工具调用顺序、决策标准、踩坑点）沉淀为 `SKILL.md`，供后续任意会话加载使用。

## 何时使用

**使用场景：**
- 用户说"把这个总结成 skill"、"保存为 skill"、"提炼成 skill"、"转成 skill"
- 会话中出现了清晰可复用的模式、提示词序列或工作流
- 解决了一个非显而易见的、可能重复出现的问题
- 解决方案具有通用性，不是特定于某个项目

**不使用场景：**
- 只是一次性的问答
- 方案只适用于某个具体代码库（应写入 CLAUDE.md/AGENTS.md）
- 没有清晰、可复用的流程

## 核心流程

### 第一步：捕获会话成果

识别用户希望保留的具体产物或工作流：

| 捕获内容 | 做法 |
|---------|------|
| 问题描述 | 用户原始请求 |
| 成功路径 | 实际奏效的步骤 |
| 工具调用 | 关键工具、参数及顺序 |
| 决策标准 | 何时选 X 而非 Y |
| 避坑点 | 差点踩的坑 |
| 最终产出 | 生成的文件、命令或模板 |

### 第二步：提炼为 Skill 格式

创建 `SKILL.md`，结构如下：

```markdown
---
name: <短横线命名>
description: <一行触发条件与用途说明>
---

# Skill 标题

## 概述
1-2 句话说明用途。

## 何时使用
- 使用场景：...
- 不适用场景：...

## 核心流程
1. 步骤一
2. 步骤二
3. 步骤三

## 速查表
| 场景 | 操作 |
|------|------|
| A | 执行 X |
| B | 执行 Y |

## 常见错误
- 错误 1 及修正方法
- 错误 2 及修正方法

## 示例
```
一个可运行或可直接复制使用的示例
```
```

### 约束（奥卡姆剃刀）

保持 skill：
- **可执行**：每个部分都告诉 agent 做什么
- **简洁**：尽量控制在 500 字以内
- **触发词丰富**：description 中应包含关键词，而非流程概述
- **自包含**：不依赖原始会话也能使用

### 第三步：创建配套文件（如需要）

如果 skill 需要脚本或模板，放在同一文件夹下：

```
skills/<skill-name>/
├── SKILL.md
├── scripts/
│   └── run.sh
└── templates/
    └── example.md
```

### 第四步：验证

完成前检查：

1. 通读生成的 `SKILL.md`
2. 确认 `name` 与文件夹名一致
3. 确认 `description` 包含清晰触发条件
4. 确认没有遗留项目专属值
5. （可选）自问：加载这个 skill 后，agent 是否知道该怎么做？

## 速查表

| 用户说法 | 操作 |
|---------|------|
| "把这个总结成 skill" | 立即执行本 skill |
| "保存这个工作流" | 如果可复用，执行本 skill |
| "下次还记得" | 若与 agent 无关，优先写入项目记忆 |
| "转成模板" | 创建 skill + 模板文件 |

## 常见错误

1. **把整段对话都 dumping 进去**
   - 修正：只总结可复用的决策路径，不要逐句复述

2. **遗留项目专属值**
   - 修正：文件名、仓库名、API 密钥等替换为占位符

3. **写成教程而非 skill**
   - 修正：聚焦 agent 应该做什么，而不是教用户学什么

4. **description 缺少触发词**
   - 修正：加入"当...时"、"如果..."、"用于..."等关键词

## 示例

**会话背景：** 用户询问如何搭建一个带测试和 Storybook 的 React 组件，你给出了一套可用流程。

**提炼出的 skill 文件夹：**

```
skills/react-component-scaffold/
├── SKILL.md
└── templates/
    └── Component.tsx.template
```

**SKILL.md 元数据：**

```yaml
---
name: react-component-scaffold
description: 当用户要求创建新的 React 组件，并希望同时包含测试和 Storybook 时触发。触发词包括"创建组件"、"初始化组件"、"React 组件带测试"等。
---
```
